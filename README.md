# 本页 BePage

纸质手帐的数字搭档。只做纸做不到、手机更顺手的事：随手记想法，记录时间花在哪里。

**纯本地，没有账号，不联网，没有广告。** 你记的内容只存在你自己的手机里。

## 它能做什么

- **收集箱**：随手记想法。长按卡片可以修改，文字里的网址可以直接点开，左滑删除，可以撤销。
- **计时**：点类目开始计时，再点一次停止；多个类目可以同时计时。内置番茄钟，专注和休息结束时会提醒你，应用被划掉也会响（见下面的“国产手机”）。
- **时间轴**：日视图按事件一张一张看每件事花了多久，周预览看一周里什么时候做了什么。
- **统计**：按日、周、月、年看每个类目花了多少时间，以及番茄钟的数据。
- **桌面小组件**：收集箱（2×2、2×1）和快捷入口（4×1）。
- **备份**：在设置里导出和导入备份文件（JSON），换手机、备份都靠它。

## 安装

1. 在 [Releases](../../releases) 页面下载最新的 `.apk` 文件。
2. 在手机上打开它安装。系统会提示“安装未知来源的应用”，需要在设置里允许一次。
3. 要求：**Android 8.0 及以上**。

### 校验下载（可选）

每个版本的发布说明里都有 APK 的 SHA-256。下载后可以核对，确认文件没有被改动过。

## 权限

| 权限 | 用来做什么 |
| --- | --- |
| 通知 | 番茄钟结束时，在你离开应用或锁屏时提醒你 |
| 精确闹钟 | 让番茄钟到点准时提醒，包括应用被划掉之后 |
| 震动 | 番茄钟结束时的提醒 |
| 开机启动 | 重启手机后，恢复进行中的番茄钟提醒 |

不申请联网权限，不读取通讯录、位置、相册。

## 国产手机

部分手机会在后台清理应用，导致番茄钟到点没有提醒。请把本页加入**电池优化白名单**，并允许**自启动**（路径因品牌而异）。第一次点番茄钟的“开始”时，应用里会有引导。

## 已知限制

- 目前只在作者自己的两台安卓手机上测试过，别的机型和系统版本可能有没发现的问题。
- 新款华为手机（HarmonyOS 5.0 及以上）不能安装安卓 APK。
- **没有自动更新**：本页不联网，新版本请回到这里的 Releases 页面查看。安卓上的 Obtainium 等工具可以帮你跟踪 GitHub 发布。
- 导入备份会**替换**当前所有数据，导入前请先导出当前数据。
- 正式版和调试版签名不同，不能互相覆盖安装；从其他来源的版本换过来，请先导出备份。

## 隐私
